# browser_profiles.txt - fingerprint profiles for hjs / hbrowser.
#
# Each profile bundles a realistic browser identity:
#   - User-Agent
#   - Client Hints (sec-ch-ua*) headers most modern sites check
#   - Accept-Language sets
#   - TLS cipher list (curated per browser family; used with
#     CURLOPT_SSL_CIPHER_LIST to avoid the default "everything" look)
#
# Format: INI-like blocks parsed by the tools.
# Lines:  [name]  ua=...  ch=... (client hints, semicolon separated)
#         accept=...  ciphers=...  lang=...
